Built 2026-11-08
- Ramp assigns firm size (revenue + employee models) and sector (NAICS model) internally; Ramp's Small 1-24 / Medium 25-99 / Large 100+ match Census employee size classes only approximately.
- BTOS wording era is assigned from each period's collection START date (goods/services before 2025-11-17; any business function from 2025-11-17; Super Intelligence from 2026-10-19), because the current Census files label all periods with the newest question text. Checked against the archive file's text.
- BTOS biweekly periods are assigned to the month their collection period STARTS, then averaged (simple mean) within month and wording era. Respondents report on the two weeks before they answer, so a period's activity runs from about two weeks before collection starts to collection end; the collection start is roughly its midpoint. Dating by collection END would compare Ramp's month with older Census answers and, with adoption rising, widen the gap slightly. Robustness: the 3-month comparison under the end-date convention is in clean/robustness_month_end.csv.
- BTOS rate = share answering 'Yes' among all respondents (denominator includes 'Do not know'). BTOS asks about the last two weeks; Ramp counts any paid AI transaction in the month, so the windows differ.
- BTOS periods 202521-202523 (Oct 6 - Nov 16, 2025) were not collected (federal shutdown); there is no BTOS value for those weeks.
- BTOS cells marked 'S' (suppressed) are skipped, not filled. Among the AI-use rows this affects only sectors 11, 21, 22, 55, none of which Ramp publishes.
- BTOS sectors matched to Ramp's on 2-digit NAICS: Information 51, Finance & Insurance 52, Manufacturing 31-33, Retail 44-45, Construction 23, Healthcare 62 (Health Care and Social Assistance, per the FRED series title), Accommodation & Food 72. BTOS sector 'XX' (multi-unit firms in several sectors) and sectors Ramp doesn't publish are dropped.
- SUSB weights are from us_state_naics_detailedsizes_2022.xlsx (2022, the latest SUSB year published), applied to 2025-26 rates: the firm-size distribution is assumed stable.
- SUSB's lowest bin '<5 employees' is treated as BTOS's 1-4 class. (Not yet checked: whether SUSB's '<5' also counts employer firms with zero employees in March.)
- BTOS size classes combined into Ramp buckets (1-24 / 25-99 / 100+) weighting each class by SUSB 2022 all-industry firm counts. The BTOS 20-49 class is split at 24/25 using SUSB's 20-24 and 25-49 bins (exact SUSB bin edges, no within-bin interpolation needed). Assumes the AI-use rate is the same for 20-24 and 25-49 firms within the BTOS 20-49 class.
- comparison tables: ratio_ceiling = 100 / census_rate, the largest Ramp/Census ratio possible even if every Ramp customer in the group paid for AI. Ratios are therefore compressed in high-adoption groups (e.g. Information). odds_ratio = [r/(100-r)] / [c/(100-c)] has no such ceiling and is reported as a footnote check on which groups stand out; it is computed from unrounded rates.

## analysis.py
- Chart 3 (firms vs workers) is an APPROXIMATION. Worker-weighted rate = sum over size classes of (class AI rate x SUSB 2022 employment in that class) / total employment. It assumes AI-using and non-using firms within a size class have the same average employment, and it applies each source's in-class rate to all U.S. firms in the class (for Ramp, that treats Ramp customers as representative within each size bucket).
- BTOS 100-249 / 250+ boundary falls inside SUSB's 200-299 bin; that bin's firms and employment are split evenly by width (half to each side). All other BTOS and Ramp size boundaries line up with SUSB bin edges exactly.
- Sensitivity: SUSB sector firm counts are 'Total' rows by NAICS sector. SUSB counts a firm in every sector it operates in, so sector counts sum to slightly more than the national firm total (6,461,497 vs 6,395,635 across all sectors).
- Charts 2-3 and the sensitivity check use the 3-month window 2026-07 to 2026-09 (clean/comparison_3mo.csv).
